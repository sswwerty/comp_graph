# Лабораторная работа № 1 по компьютерной графике

**Вариант 12 — правильный гексаэдр (куб).**

В программе на Vulkan отображаются два куба. Их можно перемещать, поворачивать, масштабировать и перекрашивать через панель управления. Первый куб также движется по трёхмерной траектории. Для окна и базовой работы с Vulkan использован учебный проект Veekay.

## Что сделано

- Добавлены перспективная и ортографическая проекции. Между ними можно переключаться во время работы программы.
- Для каждого куба отдельно настраиваются положение, поворот, масштаб и цвет.
- Первый куб движется по гармонической траектории и вращается. Анимацию можно останавливать, менять скорость движения, радиусы и частоты по трём осям, а также скорость вращения.
- Цвет кубов выбирается в панели через `ColorEdit3`.
- Цвета вершин вычисляются по их координатам. Переключатель `Procedural vertex colors` позволяет включить или отключить этот эффект.
- Оба куба используют одну геометрию, но у каждого свой uniform-буфер и свой набор дескрипторов (`VkDescriptorSet`) для матрицы модели и цвета.

В сцене есть проверка глубины, поэтому ближние грани перекрывают дальние. Матрицы модели, вида и проекции передаются в шейдеры.

## Как запустить

Проект проверен на macOS с Apple Command Line Tools, CMake и Vulkan SDK 1.4.350.1 (включая MoltenVK и `glslc`). При первой конфигурации CMake может понадобиться интернет для загрузки зависимостей.

**В VS Code:** откройте папку проекта. Для сборки нажмите `Cmd+Shift+B` и выберите `Build Lab 1`. Для сборки и запуска откройте `Terminal → Run Task… → Run Lab 1`.

**Через терминал:** перейдите в папку проекта и выполните:

```sh
cd /Users/nasy/Documents/CG/lr_1
source "$HOME/VulkanSDK/1.4.350.1/setup-env.sh"
cmake -S . -B build-local -DCMAKE_BUILD_TYPE=Debug -DCMAKE_OSX_SYSROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
cmake --build build-local --parallel 6
./build-local/testbed/testbed
```

Запускайте программу из корня проекта: она ищет шейдеры по относительным путям. Для повторного запуска после успешной сборки достаточно снова загрузить окружение SDK и выполнить последнюю команду.

## Что показать на защите

1. Переключить `Perspective projection` и показать, как меняется вид сцены.
2. В списке `Object` выбрать сначала `Animated cube`, затем `Second cube`. Изменить `Position`, `Rotation (degrees)`, `Scale` и `Object color` у каждого — настройки у кубов независимые.
3. Включить и выключить `Procedural vertex colors`, чтобы показать вычисляемую окраску вершин.
4. Остановить и запустить анимацию через `Play animation`. Изменить `Animation speed`, `Orbit radii`, `Orbit frequencies` и `Spin speed (deg/s)`. Кнопка `Reset animation phase` возвращает движение к начальной фазе.

## Где находится код

- `testbed/main.cpp` — кубы, матрицы, анимация, дескрипторы и панель управления.
- `shaders/cube.vert` и `shaders/cube.frag` — вершинный и фрагментный шейдеры.
- `source/graphics.cpp` — вспомогательный код для буферов Vulkan.
- `.vscode/tasks.json` — задачи сборки и запуска в VS Code.
